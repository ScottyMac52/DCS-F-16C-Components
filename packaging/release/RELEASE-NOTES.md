This release packages Scott's complete F-16C cockpit-control configuration.

## Downloads

- **Scott-F-16C-50-Complete-Package** — complete bundle containing the installable OVGME archive, AutoHotKey/VAICOM bridge, documentation, and checksums.
- **Scott-F-16C-50-Control-Profiles** — direct OVGME package for the DCS profiles and OpenKneeboard pages.
- **SHA256SUMS.txt** — integrity hashes for both ZIP files.

The OVGME package targets `C:\Users\vyper\Saved Games\DCS.openbeta` and installs into `Config\Input\F-16C_50` plus `KNEEBOARD\F-16C_50`.

See `Documentation/INSTALLATION.md` inside the complete package before installation.
