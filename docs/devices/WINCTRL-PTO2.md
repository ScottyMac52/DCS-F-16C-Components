# WINCTRL CarrierAce PTO2

The matching OpenKneeboard page places the PTO2 control image between the seven mapped-button
callouts and explicitly marks all other controls as unbound.

| Physical button | DCS F-16 control |
|---|---|
| JOY_BTN8 | Landing/taxi lights UP |
| JOY_BTN9 | Landing/taxi lights OFF |
| JOY_BTN12 | Landing/taxi lights TAXI (release returns OFF) |
| JOY_BTN32 | Arresting hook UP |
| JOY_BTN34 | Arresting hook DOWN |
| JOY_BTN35 | Landing gear UP |
| JOY_BTN37 | Landing gear DOWN |

The PTO2's physical hook switch now follows the F-16C cockpit HOOK switch in both positions. All other PTO2 controls are intentionally reserved; the profile does not fill unused switches with unrelated F-16 functions.
